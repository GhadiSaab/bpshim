# bp-socket without the kernel module (PoC)

Runs the unmodified `sender.c` / `receiver.c` of [bp-socket](https://github.com/DTN-MTP/bp-socket)
using `socket(AF_BP, SOCK_DGRAM, 0)` with `LD_PRELOAD`: no kernel module, no root.

```
app ──► libbpshim.so ──► libbp ──► BpaAdapter ──► dtn7-rs (HTTP, localhost)
        (C, LD_PRELOAD)   (Rust, C ABI)
```

- `shim/bpshim.c`: wraps the socket calls. `AF_BP` fds are handled here (backed by an `eventfd`); everything else goes to real libc.
- `libbp/`: synchronous Rust crate with a C ABI (`libbp/include/bp.h`, generated by cbindgen). `BpaAdapter` trait (`open/close/send/recv`) with one implementation, dtn7-rs.

## Run

Needs a Rust toolchain, a C compiler, `make`, `git`, `curl`.

```sh
make deps    # once: installs dtnd (dtn7-rs) into ./.tools
make         # builds everything; fetches bp-socket at a pinned commit
./demo.sh    # two nodes (ipn:10, ipn:20) + sender/receiver under the shim
make test    # Rust tests + shim tests against a real dtnd
```

Your own program: `LD_PRELOAD=./libbpshim.so ./yourapp`

| Env var | Default | |
|---|---|---|
| `BP_DTN7_URL` | `http://127.0.0.1:3000` | local dtn7-rs node |
| `BP_POLL_MS` | `100` | receive poll interval |
| `BP_SHIM_DEBUG` | off | `1` traces calls |

## Behaviour

- `bind` registers `ipn:<node>.<service>` with the node. `connect` stores a default destination (UDP-style).
- `sendto`/`send`/`sendmsg` return the byte count. A bound socket is the bundle's source.
- `recvfrom`/`recv`/`recvmsg` poll the node until a bundle arrives or `SO_RCVTIMEO` expires (`EAGAIN`). Signals give `EINTR`. Excess data is truncated like UDP.
- `listen`/`accept`: `EOPNOTSUPP`. Node not running: `ECONNREFUSED`.

## Limitations

- No concurrency: no threads, no async. A receive blocks its thread; sharing a BP fd between threads is unsupported.
- Not intercepted: `poll`/`epoll`/`select`, `read`/`write`, `dup`, `fcntl(O_NONBLOCK)`. Upstream's poll support is therefore not replicated.
- No BP flags (priority, custody, status reports); the `flags` argument is ignored.
- Only the `ipn:` scheme and only dtn7-rs (no `dtn:`, no ION/ud3tn).
- Only tried with the two demo programs, two nodes on localhost, on one Linux/glibc machine. Large bundles, long runs and multi-host routing are untested.
- dtn7-rs's HTTP API is unauthenticated on localhost: any local user can send as any endpoint.
- The node must already have a route to the destination (`demo.sh` links the two nodes).
- `sender.c` exits with status 7 on success (it returns `sendto`'s byte count); that is upstream behaviour.

## Possible upgrade: streaming instead of polling

`/endpoint` never blocks, so receiving is polling (up to `BP_POLL_MS` extra latency). dtn7-rs also has a
WebSocket interface that pushes bundles; a second `BpaAdapter` could use it without changing the shim.
It needs a long-lived connection per socket (shared with forked children) and a second protocol to implement.
